# ⚡ Quick Start (5 Minutes)

Get JSEBot chatting in 5 minutes.

---

## Step 1: Install (1 min)

```bash
npm install -g jsebot
jsebot --version
```

No Node.js? Get it at [nodejs.org](https://nodejs.org).

On Kali? See [INSTALL-KALI.md](INSTALL-KALI.md).

---

## Step 2: Run Onboarding (2 min)

```bash
jsebot onboard --install-daemon
```

Answer a few questions:

- **Channel?** WhatsApp, Telegram, Discord, etc.
- **AI Model?** Claude, GPT-4, or local
- **Password?** Something simple

---

## Step 3: Chat (2 min)

Send JSEBot a message on your chosen channel:

```
Hello! Can you help me?
```

**You should get a response.** ✅
